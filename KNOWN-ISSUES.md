# Known issues and scope

This is an educational baseline, not a production implementation. Search normalisation, date boundaries, validation consistency, lifecycle rules, export robustness, audit coverage, and accessibility are intentionally incomplete. The code has no authentication or role model, and it uses local SQLite without a migration workflow. The facilitator-only issue manifest contains details that are intentionally omitted here.

Do not infer that a behaviour is a business requirement merely because the application implements it. Confirm ambiguous policy with a fictional subject-matter expert during the exercise.
