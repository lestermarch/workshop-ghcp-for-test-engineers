# Legacy Notice Manager (baseline notes)

> **Baseline legacy material.** This short note was inherited with the fictional application and may be incomplete.

Legacy Notice Manager is a small internal register for navigational notices. Users can create a notice, review the register, and export a summary. It stores records in a local SQLite database. This demonstration has no sign-in and must not be used for operational decisions.

The register is intended to show title, region, severity, effective date, and status. Some controls are present in the interface but are not described here. Ask a facilitator when policy is unclear.
