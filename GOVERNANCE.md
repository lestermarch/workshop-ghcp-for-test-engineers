# Governance

Copilot output is a proposal, never an approval. A human reviewer owns the decision and verifies any rule with an appropriate subject matter expert. Preserve prompt/context, output summary, file changes, commands and results, reviewer, decision, amendments, rejected content, open questions, residual risk, and lessons.

Use `evidence/templates/AI-ACTIVITY-TEMPLATE.md` for records and `evidence/traceability.csv` for requirement–risk–test–evidence links. Avoid personal or confidential information in evidence. Treat references as synthetic and public. The reset scripts restore only tracked baseline application and sample paths after explicit confirmation; they do not erase evidence.

Automated validation supports repeatability but does not replace human security, accessibility, legal, or business review. Custom-agent tool support varies by Copilot surface; see `COPILOT-CUSTOMISATION-GUIDE.md`.
