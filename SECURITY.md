# Security policy

This repository is a fictional local workshop sample, not a production-ready notice service.

## Reporting

For a private report, use GitHub's private vulnerability reporting for the repository owner when available. Do not include real credentials, customer material, or personal data in an issue. For a public teaching-only observation, open an issue with synthetic reproduction details.

## Safe use

- Use only the synthetic records included here.
- Do not expose the app to public networks or use it for operational decisions.
- Do not add credentials or customer data to examples, prompts, test output, screenshots, logs, or evidence.
- The starting baseline intentionally contains educational weaknesses. Do not use the code or its known issues against any external system.
- Automated checks do not constitute a security assessment.

## Supported versions

Use a currently supported .NET 10 patch release. Update dependencies through reviewed pull requests and inspect release notes and advisories.
