# Workshop golden path

The participant-facing route is in [`workshop/README.md`](workshop/README.md). Complete one checkpoint before advancing; do not reveal facilitator material during initial exploration.

| Order | Lab | Output |
|---:|---|---|
| 00 | [Setup and validation](workshop/labs/lab-00-setup-and-validation.md) | Readiness status, baseline test results, and verified Copilot surface. |
| 01 | [Meet the legacy application](workshop/labs/lab-01-meet-the-legacy-application.md) | First-pass journey and observation worksheet. |
| 02 | [Understand Copilot customisation](workshop/labs/lab-02-understand-copilot-customisation.md) | Mechanism map with repository examples. |
| 03 | [Shape Copilot with instructions](workshop/labs/lab-03-shape-copilot-with-instructions.md) | Qualitative before/after scorecard. |
| 04 | [Run and create prompt files](workshop/labs/lab-04-run-and-create-prompt-files.md) | Executed existing prompt and one bounded reusable prompt. |
| 05 | [Work with specialist agents](workshop/labs/lab-05-work-with-specialist-agents.md) | Inspected and meaningfully adapted agent. |
| 06 | [Discover and install a skill](workshop/labs/lab-06-discover-and-install-a-skill.md) | Reviewed and adapted skill or documented local fallback. |
| 07 | [Explore the application in a browser](workshop/labs/lab-07-explore-the-application-in-a-browser.md) | Reproducible black-box observation. |
| 08 | [Create and run Playwright tests](workshop/labs/lab-08-create-and-run-playwright-tests.md) | Reviewed test, exact run result, and classification. |
| 09 | [Investigate, review, and record evidence](workshop/labs/lab-09-investigate-review-and-record-evidence.md) | Human decision, evidence, and traceability. |
| 10 | [Apply the approach to your context](workshop/labs/lab-10-apply-the-approach-to-your-context.md) | Safe, bounded proof-of-concept plan. |

At every stage, distinguish observed fact from inference, cite available evidence, preserve unresolved questions, and have a human accept, amend, reject, or defer the output.
