# Optional challenges

Challenges extend a lab but never block the core route. Choose one level at a time:

- **Explore:** a small extension of the guided task.
- **Apply:** use the technique on another part of the sample app.
- **Extend:** create a new reusable repository customisation or testing asset.

See the challenge at the end of each lab and the [challenge catalogue](CATALOGUE.md). From the repository root, record a completed challenge with `python scripts/workshop_progress.py challenge explore keyboard-path` in PowerShell or `python3 scripts/workshop_progress.py challenge explore keyboard-path` in Bash (replace the level and slug as needed).
