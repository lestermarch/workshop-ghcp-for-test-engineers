# Close and feedback

Ask each participant to answer briefly:

- Which Copilot activity saved time, and what review effort did it add?
- Which output did you amend, reject, or defer?
- What required tester, product, security, or accessibility expertise?
- What evidence would you need before using the approach on a real application?
- Which customisation or test would you reuse?
- What should change in the workshop environment or materials?

Record follow-up owners and dates without adding confidential project details. A successful session does not require every participant to agree on the synthetic application's policy.
