# Checkpoint LAB-04 — Run and create prompt files

**Objective check:** existing prompt was invoked or manually supplied; new prompt has objective and description frontmatter.

**Human rubric:** new prompt is bounded and read-only, distinguishes observation/inference, requests negative and boundary cases, states open questions, and asks for validation without requiring exact model wording.

**Evidence:** prompt file or backup, response critique, and keep/revise/remove decision.
