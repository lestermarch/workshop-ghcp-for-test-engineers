# Solutions and reference outcomes

Participant files contain tasks, rubrics, and recovery steps—not seeded answers. Facilitator-only outcomes remain in the existing `reference-outcomes/` and `workshop/hints/` folders and in [the facilitator answer guidance](../facilitator/ANSWER-GUIDANCE.md).

These locations are not a security boundary: anyone with repository access can read them. Facilitators should ask participants to avoid these folders until the lab says to compare outcomes. No answer file is required for successful completion; evidence-based alternatives are acceptable.
