# GitHub Copilot for testing: workshop entry point

The complete follow-along workshop is in [`workshop/README.md`](workshop/README.md). It organises the existing Legacy Notice Manager application, tests, Copilot customisations, Playwright workflows, and evidence assets into a guided 11-lab journey.

**Facilitated route:** approximately 2 hours 52 minutes, including a short break.

**Condensed route:** 45–60-minute demonstration.

**Self-paced route:** Labs 00–10 with per-lab checkpoints and recovery guidance.

Start with [setup and validation](workshop/setup/README.md), then follow the numbered labs in order. Participants should use only synthetic data and keep the facilitator answer material closed until invited.

The previous short agenda has been replaced by the structured workshop. Facilitators should use [`workshop/facilitator/README.md`](workshop/facilitator/README.md) and the existing [`FACILITATOR-GUIDE.md`](FACILITATOR-GUIDE.md) index.
